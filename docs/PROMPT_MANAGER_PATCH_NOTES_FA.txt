اصلاحیه مدیریت پرامپت‌های MarketAnalysis
==========================================

این اصلاحیه قابلیت مدیریت تعداد زیادی قالب پرامپت را به Django Admin اضافه می‌کند.

نصب
----
1) فایل ZIP را در پوشه Downloads ذخیره کنید.
2) سرور Django را با Ctrl+C متوقف کنید.
3) در ترمینال VS Code که در مسیر اصلی MarketAnalysis است و .venv فعال است اجرا کنید:

   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\MarketAnalysis_Prompt_Manager_Fix.zip" -DestinationPath "$env:USERPROFILE" -Force

   نکته: مقصد عمداً پوشه کاربری ویندوز است، چون فایل‌های ZIP از قبل پوشه MarketAnalysis/ را در مسیر خود دارند.

4) سپس اجرا کنید:

   python manage.py check
   python manage.py migrate

5) اگر هر دو دستور موفق بودند، سرور را اجرا کنید:

   python manage.py runserver

پنل مدیریت پرامپت‌ها
--------------------
http://127.0.0.1:8000/admin/analyses/prompttemplate/

با حساب Django Superuser وارد شوید.

ساخت پرامپت برای Price Action
-----------------------------
- عنوان: نام فارسی یا انگلیسی دلخواه.
- شناسه یکتا (key): انگلیسی کوچک و یکتا؛ نمونه price-action-pa-v2
- شناسه کاربرد (purpose): دقیقاً price_action
- دسته‌بندی: تحلیل بازار
- پرامپت اصلی: متن اصلی System Prompt
- دستور تکمیلی: متن ثابت اختیاری که همراه داده‌های بازار به مدل ارسال می‌شود.
- زبان خروجی: فارسی، انگلیسی یا فارسی و انگلیسی.
- فعال: روشن
- قالب پیش‌فرض: با ذخیره این گزینه، قالب پیش‌فرض قبلی همین purpose خودکار از حالت پیش‌فرض خارج می‌شود.

قالب‌های فعال با purpose=price_action در فرم تولید تحلیل قابل انتخاب هستند. اگر اپراتور قالبی انتخاب نکند، قالب پیش‌فرض همان purpose استفاده می‌شود؛ اگر پیش‌فرض تعیین نشده باشد، آخرین قالب فعال استفاده خواهد شد.

سایر کاربردها
-------------
برای ذخیره پرامپت‌های وظایف دیگر، purpose مستقل تعیین کنید؛ مانند:
- article_writer
- risk_review
- market_news_summary
- educational_explainer

این قالب‌ها در پنل مدیریت ذخیره و نسخه‌بندی می‌شوند. اجرای خودکار هر purpose جدید نیازمند اتصال آن purpose به قابلیت/گردش‌کار مربوطه در کد سامانه است؛ صرف ذخیره پرامپت باعث ایجاد قابلیت جدید نمی‌شود. در نسخه فعلی، گردش‌کار تولید تحلیل Price Action به purpose=price_action متصل است.

نسخه‌بندی و سوابق
-----------------
با هر تغییر در محتوای قالب، شماره revision افزایش یافته و نسخه جدید به‌صورت snapshot در تاریخچه ثبت می‌شود. حذف قالب‌ها از Admin غیرفعال است؛ قالب‌های قدیمی را به‌جای حذف، غیرفعال کنید.
هر تحلیل تولیدشده، متن دقیق پرامپت اصلی، دستور تکمیلی، شناسه قالب و شماره نسخه را ثبت می‌کند تا بعداً معلوم باشد تحلیل با کدام نسخه تولید شده است.

زبان خروجی
-----------
قالب اولیه Price Action با زبان «فارسی و انگلیسی» ایجاد می‌شود. در حالت دو‌زبانه، مدل باید متن فیلدهای خروجی را به شکل «فارسی: ... / English: ...» برگرداند؛ کلیدهای JSON و مقدار عددی confidence ترجمه نمی‌شوند.

ایمنی
-----
- این اصلاحیه فایل .env، رمزها، داده‌های PostgreSQL، حساب مدیر و .venv را تغییر نمی‌دهد.
- هیچ کلید API یا رمز عبوری در ZIP وجود ندارد.
- این اصلاحیه migration جدید 0002 دارد؛ اجرای python manage.py migrate لازم است.
